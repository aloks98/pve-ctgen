# v0.4.0 — Workspace TUI and secure builds

This release replaces the menu-based TUI with a full-screen workspace and adds
authenticated TLS connections, durable build jobs, node profiles, and preflight
checks. It also revises the bundled cloud-init and Flatcar configurations.

## Upgrade requirements

- Upgrade the manager and every minion together. Connections now require TLS;
  older plaintext clients and servers are incompatible.
- Restart `pvectgen-minion` after updating its binary. Run
  `pvectgen minion connect` on each host, then re-enroll its manager entry with
  the new token. Tokens contain credentials and a certificate fingerprint.
- Review existing custom build steps before adopting the new defaults with
  `pvectgen manager steps reset`. Existing imported guest configs are preserved
  unless explicitly replaced with `manager import --force`.
- Run `pvectgen manager doctor --node NODE` before building. The configured
  snippet storage must support `snippets` content and match `snippets_path`.
- Bundled guest configs allow root public-key login and include this repository's
  Titan Air and Fatman public keys. For a different environment, configure a node
  profile with `ssh_keys_mode: replace` and your own `ssh_authorized_keys` before
  provisioning guests. Guest passwords remain locked.

See the [migration guide](https://github.com/aloks98/pve-ctgen/blob/v0.4.0/docs/migration.md)
for the complete upgrade procedure and configuration details.

## Changes

- Full-screen TUI with workspace navigation, filtering, adaptive tables and forms,
  template details, reviewed build requests, and retained build logs. Ctrl+G opens
  workspace navigation; Mac users can map Command+G in Alacritty and enable
  `--mac-keys` hints. F2 is no longer required.
- TLS 1.3, certificate pinning, private credential files, and serialized identity
  provisioning for manager/minion connections.
- Durable minion jobs with cancellation, replay cursors, reconnect support, and
  accurate terminal status after disconnects. Node profiles configure storage,
  networking defaults, guest keys, and provisioning policy.
- Guarded VM/template replacement, validated requests and configuration, atomic
  file updates, serialized manager storage, verified image downloads, and cleanup
  of build subprocesses on cancellation.
- Embedded import defaults and checksum-verified atomic binary updates.
- Central guest key configuration, verified Flatcar Kubernetes extensions,
  corrected EL repository setup and Ubuntu account/service handling, Docker as
  an opt-in, and explicit upgrade/maintenance policies. Fish and the custom MOTD
  are retained.

## Validation and downloads

Validation covers race-enabled Go tests, static checks, installer smoke tests,
shell syntax, guest-key consistency, and vulnerability scanning. Live Proxmox
testing covered isolated template/build operations, six guest distribution
families, TUI workflows, and four-host minion enrollment/readiness. See the
[test record](https://github.com/aloks98/pve-ctgen/blob/v0.4.0/docs/testing.md)
for scope and limitations.

Release archives target Linux and macOS on amd64 and arm64, with SHA-256 checksums.
Building from source requires Go 1.27.3 or newer.
